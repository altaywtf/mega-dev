# mega-dev

My hub for [MEGA.dev](https://mega.dev/), Oct 26 – Nov 22, 2026.

- 4 weeks, 20 lessons (Mon–Fri), one live workshop per week.
- Each lesson ships a video, a written companion, and a repo.

## Layout

- `notes/` — my notes, one file per lesson: `week-N/NN-slug.md`.
- `workshops/` — live workshop notes and code.
- `lessons/` — lesson repo clones; gitignored, links in the notes.
